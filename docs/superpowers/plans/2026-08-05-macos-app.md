# macOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native arm64 `Path of Building.app` built by Makefile targets in this repo, using the upstream SimpleGraphic host built from a sibling clone.

**Architecture:** Workstream 1 makes the SimpleGraphic repo build on macOS (its `__APPLE__` code paths already exist) and adds the missing launcher executable (`pob`) that calls the exported `RunLuaFileAsWin(argc, argv)` with `argv[0] = <script path>`. Workstream 2 adds a `Makefile` here that wraps existing test/manifest tooling and assembles the `.app`, whose `Contents/MacOS/` directory mirrors the Windows `runtime/` layout (host requirement, see constraints). The app runs `src/Launch.lua` from this checkout (dev mode → updater disabled — required for safety, see spec decision 2).

**Tech Stack:** CMake + vcpkg (manifest mode), Ninja, Objective-C++ (launcher), GNU make 3.81-compatible Makefile, bash assembly script.

## Global Constraints

- Target **arm64 only**; macOS host machine, full Xcode installed at `/Applications/Xcode.app/Contents/Developer` (clang 21). `cmake`/`ninja` are NOT installed — Task 1 installs them via Homebrew.
- SimpleGraphic work happens in a **sibling clone at `~/dev/thirdparty/PathOfBuilding-SimpleGraphic`**, branch `feat/macos-build` off `master`. Never commit to `master`. All fixes must be **upstreamable**: minimal, platform-guarded (`if (WIN32)` / `#ifdef _WIN32` / `if (APPLE)`), never forking shared logic.
- PoB work happens in this worktree (`/Users/jucardi/dev/thirdparty/PathOfBuilding/.claude/worktrees/cross-platform-phase1`, branch `feat/crossplatform`).
- **Host filesystem contract (verified in source, binds the bundle layout):**
  - `FindBasePath()` = directory of the **executable** (`proc_pidpath`) → this is `GetRuntimePath()` and the default workdir; fonts load lazily from the relative path `SimpleGraphic/Fonts/…` against it (`engine/render/r_font.cpp:56`, `config.h:11`).
  - `ui_main.cpp:2176-2186` appends only `;lua/?.lua` (relative) to `package.path`; LuaJIT's default macOS paths contain **no exe-relative entries** (Windows' do) → the launcher MUST set `LUA_PATH`/`LUA_CPATH` to exe-dir-relative patterns before `RunLuaFileAsWin`.
  - Therefore the launcher's directory must contain: the native Lua modules (`.so`), `lua/` (pure-Lua modules), and `SimpleGraphic/Fonts/`.
- The app must keep **dev mode** on: it runs `src/Launch.lua` from this checkout and never ships a `manifest.xml` with `platform`/`branch` attributes (updater stays disabled; running it would delete the native runtime — spec decision 2).
- macOS ships GNU make 3.81: no GNU-make-4 features (no `::=`, no `.RECIPEPREFIX`, no `$(file …)`).
- Ad-hoc codesign only (`codesign --force --deep -s -`). No notarization.
- Long builds are normal: the first vcpkg run compiles ANGLE/LuaJIT/curl etc. (~30-60 min). Use Bash timeouts up to 600000 ms and background long builds; never conclude failure from duration.
- Lua files (if any) use tabs; C++/ObjC++ follows the SimpleGraphic repo's existing style (tabs); Makefile recipes use real tabs (required by make).

**Interfaces:**

- Produces: `pob` executable in the install tree. Contract: `pob [script.lua] [args…]`; script resolution order = CLI arg (unless it starts with `-` or `pob:`), `$POB_SCRIPT_PATH`, compile-time `POB_DEFAULT_SCRIPT`; a `pob://…` launch URL (Apple Event or CLI arg) is appended as the script's first Lua arg. - [ ] **Step 1: Write `macos/main.mm`**

```objc
// Path of Building launcher for macOS.
// Resolves the Lua entry script, prepares LuaJIT search paths (macOS defaults
// have no exe-relative entries, unlike Windows), captures a pob:// launch URL,
// then hands off to SimpleGraphic's RunLuaFileAsWin.
#import <Foundation/Foundation.h>
#import <CoreServices/CoreServices.h>
#include <climits>
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <mach-o/dyld.h>
#include <string>
#include <unistd.h>
#include <vector>

extern "C" int RunLuaFileAsWin(int argc, char** argv);

static std::string g_launchUrl;

@interface PobUrlHandler : NSObject
- (void)handleGetURLEvent:(NSAppleEventDescriptor*)event withReplyEvent:(NSAppleEventDescriptor*)reply;
@end

@implementation PobUrlHandler
- (void)handleGetURLEvent:(NSAppleEventDescriptor*)event withReplyEvent:(NSAppleEventDescriptor*)reply {
	NSString* url = [[event paramDescriptorForKeyword:keyDirectObject] stringValue];
	if (url) {
		g_launchUrl = url.UTF8String;
	}
}
@end

static std::string ExecutableDir() {
	uint32_t size = 0;
	_NSGetExecutablePath(nullptr, &size);
	std::vector<char> buf(size + 1);
	_NSGetExecutablePath(buf.data(), &size);
	char resolved[PATH_MAX];
	if (!realpath(buf.data(), resolved)) {
		return ".";
	}
	std::string path = resolved;
	return path.substr(0, path.find_last_of('/'));
}

int main(int argc, char** argv) {
	@autoreleasepool {
		// Capture the URL if the app was launched via the pob: scheme; the
		// event is queued at launch, a short run-loop spin collects it.
		PobUrlHandler* handler = [PobUrlHandler new];
		[[NSAppleEventManager sharedAppleEventManager]
			setEventHandler:handler
			andSelector:@selector(handleGetURLEvent:withReplyEvent:)
			forEventClass:kInternetEventClass
			andEventID:kAEGetURL];
		[[NSRunLoop currentRunLoop] runUntilDate:[NSDate dateWithTimeIntervalSinceNow:0.15]];

		std::string script;
		if (argc > 1 && argv[1][0] != '-' && strncmp(argv[1], "pob:", 4) != 0) {
			script = argv[1];
		} else if (const char* env = getenv("POB_SCRIPT_PATH")) {
			script = env;
		}
#ifdef POB_DEFAULT_SCRIPT
		if (script.empty()) {
			script = POB_DEFAULT_SCRIPT;
		}
#endif
		if (script.empty()) {
			fprintf(stderr, "pob: no Lua entry script; pass a path or set POB_SCRIPT_PATH\n");
			return 1;
		}
		char resolved[PATH_MAX];
		if (!realpath(script.c_str(), resolved)) {
			fprintf(stderr, "pob: script not found: %s\n", script.c_str());
			return 1;
		}

		std::string exeDir = ExecutableDir();
		setenv("LUA_PATH", (exeDir + "/lua/?.lua;" + exeDir + "/lua/?/init.lua;;").c_str(), 1);
		setenv("LUA_CPATH", (exeDir + "/?.so;;").c_str(), 1);
		// Fonts/screenshots resolve relative to the default workdir, which the
		// host derives from the executable's directory; make cwd match it too.
		chdir(exeDir.c_str());

		std::vector<char*> args;
		args.push_back(resolved);
		std::string url = g_launchUrl;
		if (url.empty() && argc > 1 && strncmp(argv[1], "pob:", 4) == 0) {
			url = argv[1];
		}
		if (!url.empty()) {
			args.push_back(url.data());
		}
		for (int i = 2; i < argc; i++) {
			args.push_back(argv[i]);
		}
		return RunLuaFileAsWin((int)args.size(), args.data());
	}
}
```

- [ ] **Step 3: Write `scripts/build-macos-app.sh`**

```bash
#!/usr/bin/env bash
# Assembles Path of Building.app from the SimpleGraphic install tree.
# Contents/MacOS mirrors the Windows runtime/ layout: the host resolves fonts,
# lua modules, and native modules relative to the executable's directory.
set -euo pipefail

: "${SG_DIST:?SG_DIST not set}"
: "${BUILD_DIR:?BUILD_DIR not set}"
: "${POB_ROOT:?POB_ROOT not set}"

for f in pob libSimpleGraphic.dylib lcurl.so lua-utf8.so socket.so lzip.so; do
	if [[ ! -e "$SG_DIST/$f" ]]; then
		echo "error: missing $SG_DIST/$f — run 'make macos-runtime' (see docs/crossPlatform.md)" >&2
		exit 1
	fi
done

APP="$BUILD_DIR/Path of Building.app"
MACOS_DIR="$APP/Contents/MacOS"
rm -rf "$APP"
mkdir -p "$MACOS_DIR"

# Native runtime: launcher (renamed to match CFBundleExecutable), dylibs, Lua modules
cp "$SG_DIST/pob" "$MACOS_DIR/Path of Building"
find "$SG_DIST" -maxdepth 1 \( -name '*.dylib' -o -name '*.so' \) -exec cp {} "$MACOS_DIR/" \;
# Pure-Lua modules and fonts from the repo's platform-neutral runtime dir
cp -R "$POB_ROOT/runtime/lua" "$MACOS_DIR/lua"
mkdir -p "$MACOS_DIR/SimpleGraphic"
cp -R "$POB_ROOT/runtime/SimpleGraphic/Fonts" "$MACOS_DIR/SimpleGraphic/Fonts"

cp "$POB_ROOT/scripts/macos/Info.plist" "$APP/Contents/Info.plist"

# The app runs the Lua program from this checkout (dev mode: updater disabled,
# user data lives in the checkout). POB_SCRIPT_PATH overrides at launch.
cat > "$MACOS_DIR/launch-env.sh" <<EOF
#!/bin/bash
export POB_SCRIPT_PATH="\${POB_SCRIPT_PATH:-$POB_ROOT/src/Launch.lua}"
exec "\$(dirname "\$0")/Path of Building.bin" "\$@"
EOF

# Wrapper trick: CFBundleExecutable -> shell wrapper baking the script path.
mv "$MACOS_DIR/Path of Building" "$MACOS_DIR/Path of Building.bin"
mv "$MACOS_DIR/launch-env.sh" "$MACOS_DIR/Path of Building"
chmod +x "$MACOS_DIR/Path of Building" "$MACOS_DIR/Path of Building.bin"

codesign --force --deep -s - "$APP"
echo "built: $APP"
```

Note: the shell-wrapper indirection keeps `POB_DEFAULT_SCRIPT` out of the SG build (no PoB-specific path baked into the upstreamable repo). The `.bin` still finds fonts/modules because both files sit in `Contents/MacOS`; the host resolves against the real executable's directory (`proc_pidpath` traverses the exec'd binary, not the wrapper). LUA_PATH/CPATH are set by the launcher itself relative to its own location.
